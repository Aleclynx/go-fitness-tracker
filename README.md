# Фитнес-трекер на Go.
Простой модуль для разбора данных трекера: тренировки (бег и ходьба) и ежедневные прогулки. Считает дистанцию, скорость и калории.

Структура проекта.
Пакеты разложены по папкам internal/:
- spentenergy — формулы: дистанция, средняя скорость, калории при беге и ходьбе;
- personaldata — структура с именем, весом и ростом пользователя;
- trainings — парсит строки вида "3456,Бег,0h30m" и выводит отчёт по тренировке;
- daysteps — парсит строки вида "678,1h20m" и выводит отчёт по прогулке;
- actioninfo — интерфейс DataParser и функция Info(), которая обрабатывает слайс строк. Работает одинаково для обеих структур;
Точка входа — cmd/tracker/main.go. Редактировать не нужно, там уже прописаны тестовые данные.

Как запустить.
Нужен Go версии 1.22 или новее. В корне проекта:
go run ./cmd/tracker

Примеры входных данных
Тренировки:
3456,Ходьба,3h00m
678,Бег,0h5m

Прогулки:
678,0h50m
792,1h14m
Пока всё через fmt.Println, без баз данных и конфигов.
